# U-Linker Project

U-Linker 是一款基于前后端分离架构的协作平台。

## 🛠 技术栈 (Tech Stack)

### 前端 (Frontend)
- **Framework**: Vue 3 (Composition API)
- **Build Tool**: Vite
- **Network**: Axios
- **Language**: JavaScript/TypeScript

### 后端 (Backend)
- **Framework**: Flask
- **Database ORM**: SQLAlchemy
- **Language**: Python 3.9+

## 📂 目录结构
- `/Frontend`: Vue3 前端项目源码
- `/Backend`: Flask 后端 API 服务

### 1. 启动后端
```bash
